This directory contains the Dart application code for the EuroONE prototype. The app now uses Riverpod, GoRouter, mock data, and role-based screens for Educando, Educador, and Gestao.

## Summary

- .context.md - orientation note for this directory.
- main.dart - starts the Flutter app with `ProviderScope` and `EuroOneApp`.
- app/ - Material app, theme, and GoRouter configuration.
- core/ - shared models and mock data.
- features/ - role-specific app features and screens.
- shared/ - reusable widgets and responsive layout helpers.

## Constraints

- MUST keep `main.dart` as the application entry point while `pubspec.yaml` has no alternate Flutter entry point configured.
- MUST keep external data mocked in `core/data/mock_data.dart` until backend integration is explicitly added.

## Guidance

- SHOULD keep role redirects centralized in `app/routes.dart`.
- SHOULD keep widgets presentation-focused and place shared UI in `shared/`.
